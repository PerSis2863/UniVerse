# STORMFALL

STORMFALL is an original tactical battle royale for **Unity 6.6 (`6000.6.7f1`) + URP 17**.
All of its content is generated by code: meshes, PCM audio, URP materials, the island terrain,
the HUD and the bots. No imported art or audio files are needed.

## Quick start

1. Open this folder in Unity `6000.6.7f1`.
2. Run **Tools → Build Complete Stormfall Game**.
3. Press **Play**. Click the Game view to capture the mouse.

The builder generates every asset under `Assets/Stormfall/Generated/` and saves the playable
scene to `Assets/Stormfall/Scenes/Stormfall.unity`, which it adds to Build Settings. You can
re-run it at any time to regenerate everything.

> Active Input Handling is set to **Both**. If you change it, Unity asks for an editor
> restart, which is needed once.

## Web version

**Tools → Build Stormfall for Web (WebGL)** writes a browser build to `Builds/WebGL` (about 12 MB,
Brotli-packed, lighter graphics in the browser: shorter shadows, no SSAO). The UniVerse site serves
it at `/play/stormfall` on computers only; copy a new build in with
`node apps/web/scripts/stormfall-web.mjs <build folder>` from the UniVerse repo.

## What's in the match

| System | Highlights |
| --- | --- |
| Movement | Quake-style `PM_Accelerate`/`PM_Friction`. Sprint, double-tap tactical sprint (+8° FOV), slide and slide-cancel, dolphin dive, prone, ledge mantle (0.6–1.6 m). |
| Infil | You ride the *Skyhauler* cargo aircraft across the island and jump with **Space**. Free-fall at 50–65 m/s, then parachute (cut and redeploy with **C**). Updraft vents relaunch you. |
| Gunplay | MCR-4 Carbine, Striker-9 SMG and KATT-AMR. 200 ms cubic ADS onto an emissive holo reticle, dual-spring recoil, sway, staged reloads that cancel and resume, mounting (−70% recoil), hold-breath scope, simulated projectiles with drop. |
| Survival | 100 HP plus 3 × 50 armour cells (hold **G**), 5 s regen at 40 HP/s, downed state with Stim self-revive, gas mask. |
| Blight ring | 5 collapsing stages with a volumetric wall. 12 HP/s outside it, ignoring armour. |
| Reboot Trial | STORMFALL's second chance: destroy 6 sentry drones in 60 s to redeploy. |
| Economy | Cash, blue/orange humming caches, rarity loot (grey→gold) with comparison cards. Supply Terminals sell cells, gas mask, stim, Recon Pulse, Orbital Lance and Kit Pod. Kit Pods give legendary 5-attachment weapons and 4 perks. Field Ops contracts: Manhunt, Salvage Run, Uplink. |
| Bots | 8 squads × (Rifleman, Flanker, Sniper). They fight from cover, flank campers, show sniper glint, throw cooked frags, revive squadmates and call out on the radio. Hitboxes: head 1.6×, upper torso 1.1×, lower torso 1.0×, limbs 0.85×. |
| World | 800 m island, the 3-lane *Kestrel Airfield* arena, 7 named POIs with door-and-roof buildings, about 430 wind-swaying trees. |
| HUD | Compass tape with gunfire markers, rotating minimap and **M** tac-map, dynamic crosshair, 3-tier hitmarkers, XP feed, damage arcs, status and weapon docks, menus, overlays. |
| Post FX | ACES tonemapping, bloom, SSAO, vignette, ADS depth of field, sun lens flare, fog. |

## Controls

| Key | Action |
| --- | --- |
| WASD / Mouse | Move / look |
| Shift (double-tap) | Sprint / tactical sprint · hold breath while scoped |
| C | Crouch · slide · hold to dive · cut chute |
| Space | Jump · mantle · slide-cancel · jump from aircraft · deploy chute |
| LMB / RMB | Fire / aim |
| R · B · Q | Reload · fire mode · frag |
| 1 / 2 / wheel | Switch weapon |
| G (hold) | Insert armour cells |
| F | Interact · hold to self-revive |
| V | Mount on cover |
| 3 | Killstreak |
| M | Tac-map |
| Esc / Enter | Free cursor / play again after the match |
